# Tata Tani website

Static one-page site for the Tata Tani fertilizer brand by PT Jore Agro Mandiri.
Open `index.html` in a browser. No build step.

## Before going live
- Replace the contact placeholders: `[email]`, `[nomor]`, `[alamat]`, `[Nama pimpinan]`.
- Set the WhatsApp number: search `var WA=` in `index.html` (digits only, country code first).
- Confirm every claim on the packaging photos (SNI, "Organik Indonesia", permit numbers) is backed by official documents.
- The contact form only prepares a message (copy or WhatsApp). It does not send anything to a server.
